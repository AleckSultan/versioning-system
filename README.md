# Nyeri IT Solutions

License and subscription management portal.

## Launch the app

From the project folder, run:

```powershell
npx -y -p node@20 -c "npm start"
```

Then open [http://localhost:3000](http://localhost:3000) in your browser. The project uses Node.js 20 for its SQLite dependency.
